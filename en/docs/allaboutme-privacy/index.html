AllAboutMe — Privacy Policy

App: AllAboutMe (com.twentypoundbird.allaboutme)

Developer / operator: TwentyPoundBird

Privacy / support contact: feedback.tpb+allaboutme@gmail.com

Effective date / last updated: October 23, 2026

This policy describes the current version of the AllAboutMe Android app. AllAboutMe is primarily an offline personal organizer. You do not need an AllAboutMe account or Google sign-in to use it. Manual file-based backup and restore are available to users through Android's system file picker. Automatic scheduled backup is not available. The app also contains a separate, experimental direct Google Drive API feature used solely by the developer with the developer's own authorized Google account; this feature is not available to regular users.

1. What AllAboutMe does

AllAboutMe helps you organize profiles and contact information, interests and preferences, custom fields, personal notes, organizations and relationships, events and profile photos. You decide which information to enter. Some records may contain information about other people.

2. Information stored on your device

Your records and photos are stored in the app's private storage on your Android device. When you select a profile photo, the app uses the Android system photo picker and stores a processed copy locally. AllAboutMe does not automatically read your phone's contacts, SMS messages or call logs.

AllAboutMe does not require an account with TwentyPoundBird. It does not automatically synchronize your records with our servers and does not include third-party advertising or analytics. Our company does not receive your local profile database.

3. Manual backup and restore using Android

When you choose “Save to file”, AllAboutMe prepares a backup archive and opens Android's system file picker (the Storage Access Framework, or SAF). You choose the location where the file will be saved. Depending on the storage providers installed on your device, this may be device storage, Google Drive, or another provider. AllAboutMe writes only to the document location selected through the system picker. This manual SAF operation does not request Google Drive OAuth permissions or call the Google Drive API directly.

You can restore a backup by choosing a file through the same Android system picker. The app reads the file you select, validates it, shows a preview, and restores records only after you confirm that existing local data will be replaced. A backup may contain profiles, names and contact details, notes, custom fields, preferences, organizations, relationships, events and saved profile photos.

These actions are manual. In the normal user-facing mode, AllAboutMe does not automatically upload or synchronize backups, browse external storage, or delete external files. The “Automatic backup” area is disabled for regular users. A separate developer-only testing feature is described in Section 5.

4. External storage providers, including Google Drive

If you explicitly select Google Drive or another cloud provider in the Android picker, the provider may transfer and store your chosen backup file under its own terms and privacy policy. Sign-in for files saved through SAF is handled by Android and the chosen storage provider. It is not the app's experimental Google API sign-in. Which providers are available depends on your device and installed apps.

When you use SAF, AllAboutMe does not obtain Google OAuth tokens, access Google Contacts or Gmail, or request permission to browse unrelated Google Drive files. The app's separate developer-only Google API functionality uses restricted Google OAuth access as described below. For Google's handling of stored files, see the Google Privacy Policy and Google Drive terms.

5. Restricted developer-only Google Drive API testing

This version includes experimental Google sign-in and direct Google Drive API backup functions for the developer's own testing only. The Google Cloud OAuth configuration currently permits only the developer's personal Google account to authorize this feature. Other users, including users who activate a hidden debug mode in the app, are not authorized to access the Google Drive API integration. No Google account is required for normal app use or manual SAF backups.

When the developer explicitly uses this experimental feature, AllAboutMe requests the limited drive.appdata permission to create, list, retrieve, restore or delete the app's own backups in the developer's hidden Google Drive application-data folder (appDataFolder). This permission does not grant access to Google Contacts, Gmail or unrelated Drive files. Hidden app-data backups are not visible among ordinary files in Google Drive and are separate from files saved using Android's system picker.

The selected testing account is remembered locally on the developer's device. Google authorization is used when the experimental feature is invoked; access credentials are not intentionally uploaded to TwentyPoundBird servers. Data in a test backup may include the same kinds of records and photos described in Section 3. The developer initiates each backup or restore action manually; the experimental feature does not provide scheduled or automatic cloud synchronization. Google handles data stored in the developer's own account under its applicable terms and privacy policy.

6. Backup file security

AllAboutMe provides optional password protection for backup archives, including manual SAF exports and developer-only test backups. Password-protected archives use password-based key derivation and AES-GCM encryption before the file is handed to the selected storage provider. The backup password is not sent to TwentyPoundBird; you must keep it because an encrypted backup cannot be restored without the correct password.

Without a password, a backup archive is not additionally encrypted by AllAboutMe. Anyone who obtains a readable copy of the file may be able to access its contents. Device and cloud storage providers may offer their own encryption or access protections. We recommend protecting files that contain sensitive personal information.

7. Sharing, support and advertising

TwentyPoundBird does not receive or sell ordinary users' local app records and does not use those records for advertising, profiling or training general-purpose AI models. If you choose to export a backup through SAF, you determine which storage provider receives the file. The separate Google Drive API integration is restricted to the developer's own Google account for testing, not to ordinary users' accounts. The app does not automatically share users' records with other users or services.

If you choose to contact support, the app opens your email application. We can read the email and any information you voluntarily send us in order to provide support. Your email provider's terms and privacy practices also apply; avoid attaching sensitive personal records unless necessary.

8. Retention, deletion and existing backups

Local records remain on your device until you modify or delete them, clear the app's data or uninstall it. You can delete individual entries or use the “Delete all data” function. Removing app data does not delete backup files that you previously saved through Android's system picker.

Files exported to device storage, Google Drive or other providers remain under your control in those locations. To remove a backup, delete it from the storage provider you selected. Uninstalling AllAboutMe does not automatically delete those exported files. Conversely, deleting a backup file does not delete the records currently stored in AllAboutMe.

Developer test backups: Backups created through the experimental Google Drive API are kept in the developer's own hidden Google Drive app-data storage, separately from files saved through SAF. The authorized developer can manage those backups using the restricted testing interface, or remove the app's hidden data using available Google account management controls. Uninstalling the app does not necessarily remove such cloud-stored backups. These experimental backups are not accessible through the normal SAF file picker.

9. Children and information about other people

AllAboutMe's offline features can be used without registration and may be used by children. Parents and guardians can help children decide what data to enter and where to save any exported copies. A third-party storage provider, including Google Drive, may impose account-age or parental-supervision requirements under its own rules. The experimental Google Drive API integration is not available to children or other regular users.

Because the app allows you to record information about other people, please enter, export or share that information only when you have an appropriate right or permission to do so. Avoid disclosing another person's sensitive information without permission.

10. Changes to this policy

We may update this policy when AllAboutMe's functionality or data practices change. The effective date above identifies this version. If the currently developer-only Google Drive API functionality is made available to other users, or if scheduled cloud backups are introduced, we will update this policy and any required Google Play disclosures before that change.
